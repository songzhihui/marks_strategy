# 霍华德·马克斯选股策略（币安合约）

[English](README.md) | 简体中文

本工具通过公开行情接口读取数据，无需 API Key，不会下单。界面、日志与生成报告目前为中文。

用霍华德·马克斯（Howard Marks，橡树资本）的投资思想，对币安 U 本位永续合约做选股：
**24 小时成交额前 30 的加密货币合约 + 全部股票合约**。数据全部通过 ccxt 从币安获取。

股票合约包括美股、美股 ETF、港股、韩股和 A 股，按币安元数据里的 `underlyingType` 识别。
大宗商品、外汇、指数合约不是股票，不纳入。OPENAI、ANTHROPIC 这类上市前合约没有真实股价，默认也不纳入。

## 思想如何落到数据上

| 马克斯的观点 | 策略里的做法 |
|---|---|
| **我们无法预测，但可以知道身处周期的什么位置**（周期与钟摆） | 市场温度计：估值（价格相对长期均线）、情绪（资金费率）、宽度（站上长期均线的比例）、动量（90 日涨跌）四项加权，得到 0~100 的温度。加密和股票分别量温度，杠杆和反向产品不参与。 |
| **别人越不谨慎，我们越要谨慎** | 温度决定总仓位：冰点 100%，偏冷 80%，中性 60%，偏热 40%，过热 20%。同时切换因子权重：冷的时候偏重价值和逆向情绪，热的时候偏重风险控制和不对称。 |
| **风险是永久损失的可能性，不是波动** | 先排除输家：杠杆和反向产品、上市太短（未经周期检验）、流动性不足、较一年高点跌超 90%（加密）或 70%（股票）、资金费率过高、价格远高于长期均线。 |
| **价格低于价值才是好投资** | 价值因子：价格低于长期均线的程度、距一年高点的回撤。合约没有财报，这里只能用价格偏离长期均线来近似“便宜”。 |
| **第二层次思维、逆向投资** | 逆向情绪因子：资金费率越低、多空人数比越低、持仓量膨胀越少，说明大众越悲观或越不拥挤，得分越高。 |
| **不对称性：上涨时跟上，下跌时少跌** | 不对称因子：基准上涨日的平均跟涨比例减去基准下跌日的平均跟跌比例，再除以它的标准误得到 t 值，避免高波动标的靠运气得高分。加密以 BTC 为基准，股票以 SPY 为基准。 |
| **成功的道路更多来自风险控制，而非进攻** | 风险因子：下行波动率、最差 5% 交易日的平均亏损、成交额。 |
| **耐心等待机会，不追求抄到最低点** | 企稳因子：距 90 日最低点过了多少天、是否站回 20 日均线。5 天内刚创新低的列入“观察”，不接飞刀。 |
| **你无法预测，但可以做好准备** | 不押单一标的：按波动率倒数分配仓位，单只不超过 25%，候选不够时多持现金。 |

所有价格偏离都换算成“几个标准差”（σ），波动大的山寨币和波动小的股票用同一把尺子。
因子在各自板块内做百分位排名，加密和股票不混排。

## 数据处理

- **长期均线**：最多 200 日。币安的股票合约大多上市不到 200 天，这些用上市以来的均线，至少要有 100 天才计算。
- **拆股复权**：股票合约的历史 K 线没有按拆股复权，拆股当天会出现一根假的暴跌。单日跳变的幅度达到日常波动的 20 倍，
  且比例贴近常见拆股比例时，视为拆股，把之前的价格复权。只处理股票，加密货币的暴跌是真实的。复权记录会打印在日志里。
- **杠杆和反向产品**：某合约的日收益几乎正好是另一个合约的 1.5 倍以上（相关性至少 0.97），视为它的杠杆或反向产品，
  例如 TQQQ 约等于 3 倍 QQQ。与基准相关性低于 -0.5 的视为做空或波动率产品，例如 UVXY。
  跟踪标的不在币安上的 TMF、TBT 放在手工名单里。这些产品每日再平衡，长期持有有损耗，一律回避。

## 运行

```bash
pip install -r requirements.txt
python gui.py                # 图形界面（PyQt6）
python main.py               # 命令行，默认走本机代理 http://127.0.0.1:7890
python main.py --refresh     # 忽略当天缓存，重新下载
python main.py --proxy ""    # 不用代理直连
python main.py --inspect     # 打印币安合约分类字段，核对股票合约识别是否正确
```

代理也可以用环境变量 `BINANCE_PROXY` 指定。首次运行需要逐个下载日线、资金费率、持仓量和多空比，大约几分钟；
同一个 UTC 日内再次运行会读取 `cache/` 下的缓存，缓存只保留最近 3 天。

## 图形界面

- 顶部填代理地址，点“运行选股”。下载在后台进行，进度条显示进度，可以随时点“停止”。
- 加密和股票各占一个标签页。左上是市场温度和各分项读数，右上是入选组合和仓位。
- 下方表格列出全部标的，按“候选、观察、回避”着色，点表头可以按任意一列排序。
- 选中任意一行，右侧显示该标的最近一年的走势图和全部因子读数。股票走势图是拆股复权后的价格。
- 表格里被截断的文字，鼠标悬停可以看全文。界面跟随系统的深浅色主题。
- “检查合约分类”把币安返回的合约分类字段打印到日志，用来核对股票合约识别规则。
- 每次运行完都会和命令行一样，把报告和明细写到 `output/`。

## 输出

- `output/report_日期.md`：每个板块的市场温度、入选标的与仓位、观察名单、回避名单及原因。
- `output/selection_日期.csv`：所有标的的因子原始值、五组因子得分、综合分、状态和仓位，便于自己复核。

仓位是“该板块资金”的比例，加密和股票之间如何分配资金由你自己决定。

## 调参

所有参数都在 `config.py`：选股范围、过滤阈值、拆股和杠杆产品的识别阈值、温度分档与仓位、各风格的因子权重、
每个板块的入选数量、单只上限。

## 局限

- 合约没有基本面数据，“价值”只能用价格相对长期均线来近似，这与马克斯对内在价值的判断不是一回事。入选名单应作为研究起点，由人来做第二层次思考。
- 币安的持仓量和多空比历史只提供最近 30 天，情绪因子只能看短期。
- 股票合约上线时间短，上市不足 100 天的没有长期均线，相应分项会自动跳过，报告里注明了每个温度分项的样本数。
- 拆股和杠杆产品是从价格数据推断的，阈值之外的情况可能漏判或误判，回避原因都写在报告里，可以人工复核。
- 策略没有经过回测。直接回测还会有幸存者偏差，因为成交额前 30 是按今天的排名选的。
- 本项目只是筛选工具，不构成投资建议。合约带杠杆，请自行控制风险。

## 环境与项目结构

需要 Python 3.10 或更高版本及兼容的依赖包，建议先用 `python -m venv .venv` 创建虚拟环境，再用 `python -m pip install -r requirements.txt` 安装。Windows 可在安装依赖后运行 `run.bat` 启动界面。

`main.py` 和 `gui.py` 为入口，`pipeline.py` 共用流程；`data.py` 负责数据与缓存，`factors.py` 计算因子，`cycle.py` 判断温度，`strategy.py` 评分、过滤与配仓，`report.py` 导出报告，`config.py` 集中配置。

命令行代理优先级：`--proxy` → `BINANCE_PROXY` → `config.PROXY`。部分旧版 PowerShell 会丢弃空字符串参数；如直连命令提示缺少参数，可清除环境变量覆盖并在 `config.py` 设置 `PROXY = ""`。

缓存日期为 UTC 下载日期，报告文件名采用所有已下载标的中最新的已收盘日线日期；同日期报告会覆盖。无任何评分数据时不生成新的 CSV。行情发现仍需联网，缓存只复用逐标的数据。单只仓位封顶后的余额保留现金，不重新分配。

项目是对马克斯思想的独立演绎，不代表橡树资本官方策略；建议仓位未建模保证金、强平或交易成本。
